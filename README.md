# TrayMenu

Утилита для Windows 11: иконка в системном трее, по нажатию ЛКМ открывается меню программ для запуска (аналог панели инструментов в предыдущих версиях Windows).

## Возможности

- Меню программ в трее (формируется из ярлыков программ в папке, папка указывается в настройках)
- Вложенные подменю (подпапки)
- Иконки пунктов меню берутся из ярлыков программ
- Настройки: 
  - путь к папке
  - автозапуск с Windows
- Редактор меню: 
  - изменение порядка (drag-and-drop)
  - перенос между подменю (подпапками)
  - создание подменю (новой подпапки папки)
  - переименование подменю и ярлыка
  - удаление подменю и ярлыка
- Автообновление меню при изменениях в папке с ярлыками
- Защита от множественного запуска

Конфиг: `%AppData%\TrayMenu\config.json`  
Порядок пунктов меню: `%AppData%\TrayMenu\order.json`

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 10+ для сборки
- Windows 10/11 (нужен .NET Desktop Runtime 10, либо self-contained publish)

## Сборка и запуск

```powershell
dotnet build
dotnet run --project TrayMenu
```

Exe после сборки: `TrayMenu\bin\Debug\net10.0-windows\TrayMenu.exe`

Публикация без зависимости от установленного runtime:

```powershell
dotnet publish TrayMenu -c Release -r win-x64 --self-contained true -o publish
```

## Использование

1. Запустите приложение — появится иконка в трее.
2. ЛКМ по иконке — откроется меню программ
3. ПКМ по иконке — откроется меню «Настройки…» / «Редактировать меню…» / «Выход»
4. В настройках укажите папку с ярлыками программ (`.lnk`).
5. При необходимости включите «Запускать с Windows».
6. «Редактировать меню…» — позволяет менять порядок пунктов, создавать подменю, переносить пункты в\из подменю, переименовывать и удалять подменю и пункты меню.
